# Snowhush Linux/X11 0.6.0

The first public release of the unofficial Linux/X11 fork of
[Snowhush](https://github.com/mbezruchko/Snowhush).

- One transparent, click-through overlay per X11 monitor.
- Shared Snowhush snow simulation, window snow and cursor interaction.
- Notification-area menu, settings, Open at Login and single-instance behavior.
- Hides on lock and full-screen windows, including when started while locked.
- Installer and checksummed tarball; see `linux/README.md` for requirements and known limits.

This is a beta build. The upstream macOS/Windows sources are reused unchanged.
