# Changelog

## 0.6.0 — 2026-10-28

The first public Linux/X11 fork release.

- Adds a native X11 overlay build for Linux, using the shared Snowhush simulation and geometry.
- Draws one transparent, click-through overlay per monitor on the EWMH work area.
- Adds the notification-area menu, settings persistence and Open at Login.
- Hides while the screen is locked or a full-screen window covers a monitor, and at startup in a
  locked session.
- Adds a single-instance lock, a user-service installer and a checksummed release tarball.
- Documents the Linux/X11 limitations and the AI assistance used for this fork.

The upstream 0.5.2 macOS/Windows code is reused unchanged.
